# GACEB Scholar — Super Multi-page Edition
Responsive multi-page learning website for Uganda curriculum O-Level and A-Level learners. Start at `index.html`. See `SETUP.md` for the no-code upload guide and backend prerequisites.


This ZIP is a starter project built from the available GACEB Scholar files. Supabase credentials are intentionally not included. Read SETUP.md before publishing. The site cannot be considered fully live until the existing Supabase project is connected, migration reviewed, and browser/backend flows tested.
